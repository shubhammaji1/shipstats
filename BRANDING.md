# ShipStats Signal Beacon identity

The selected logo is concept 02, Signal Beacon: a pixel-textured stone plinth, an emerald/cyan beacon, a vertical light beam, and three connected floating data nodes. It represents developer products sending metrics into one monitoring hub. The artwork is text-free, transparent, and static.

- `media/shipstats-icon.png`: transparent Signal Beacon logo used by the extension manifest, dashboard and README.
- `media/shipstats.svg`: simplified monochrome beacon/data-node glyph for the VS Code activity bar.
- No lettering or concept captions are embedded in the logo. Application titles, commands and settings still use the ShipStats name.

The PNGs were created using the built-in imagegen tool. The activity-bar SVG was authored directly for small-scale readability. Generation prompts are recorded below for future revisions.
